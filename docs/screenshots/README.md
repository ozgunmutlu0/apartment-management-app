# Screenshots

Screenshots are taken on an iOS 26 device (Liquid Glass) and saved as PNG in this folder.

Naming: `<screen>.png` for light mode and `<screen>-dark.png` for dark mode.

| Screen | Light | Dark |
|---|---|---|
| Home | `home.png` | `home-dark.png` |
| Tickets | `tickets.png` | `tickets-dark.png` |
| New ticket | `new-ticket.png` | `new-ticket-dark.png` |
| Announcements | `announcements.png` | `announcements-dark.png` |
| Dues | `dues.png` | `dues-dark.png` |
| Profile | `profile.png` | `profile-dark.png` |

Use the demo accounts from the main README; do not include real personal data.
